# Самосбор: Ликвидатор — Этаж 1324

Хоррор от первого лица в браузере (Three.js r128). Версия 1.0.0.

## Файлы
- `index.html` — страница игры
- `app.js` — код игры
- `icon.svg`, `manifest.webmanifest` — иконка и установка как приложение
- `sw.js` — офлайн-кэш (работает только по HTTPS)
- `vendor/` — сюда положить `three.min.js` как запасной вариант CDN

## Запуск локально
Не открывайте `index.html` двойным кликом. Запустите сервер в папке:
```
python -m http.server 8000
```
и откройте http://localhost:8000

## Публикация
- **itch.io**: заархивируйте содержимое папки (index.html в корне), тип проекта HTML, включите «Fullscreen button».
- **GitHub Pages / Netlify / Vercel**: загрузите папку как есть.

## Режим разработчика
Консоль (Ctrl+Shift+`) и логи отключены в релизе. Включить: `?dev=1` в адресе, выключить: `?dev=0`.

## Управление
WASD, мышь, Shift бег, Space пинок, R дверь, F фонарик, E слушать. Esc пауза. Клавиши меняются в настройках. На телефоне есть сенсорные кнопки.

## Скриншоты
F9: скрыть интерфейс, F8: сохранить чистый кадр в PNG.

## Кооператив (до 4 игроков)
Главное меню → КООПЕРАТИВ. Хост создаёт комнату и даёт код из 5 символов (или ссылку `?room=КОД`).
- Одинаковые этажи у всех, общий цикл Самосбора (по хосту), видно друг друга на одном этаже, чат по Enter.
- Связь P2P через WebRTC (PeerJS), свой сервер не нужен.
- Ограничения: монстры, двери и лут у каждого свои. Строгие корпоративные/мобильные сети могут не соединиться без TURN-сервера (добавляется в ICE в блоке v24).
